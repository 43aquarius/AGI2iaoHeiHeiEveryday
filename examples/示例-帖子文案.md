1️⃣ xerj-org/xerj
⭐ 7.4k 星 · Rust

XERJ是用Rust写的AI搜索工具，能自动索引代码、文档、日志和PDF文件。它用40倍于grep的token，但效果更好，支持Elasticsearch兼容的搜索。安装很简单：curl -fsSL httpsxerj.orgget | sh，然后xerj autoindex ~/my-project就能开始使用。

搜索时直接用xerj search命令，支持定义查找xerj def，还能查看它为你节省了多少token。经常需要搜索大量代码的人会喜欢这个工具，特别是那些厌倦了grep和sed的人。

🔗 https://github.com/xerj-org/xerj

2️⃣ akitaonrails/ai-memory
⭐ 9.7k 星 · Rust

ai-memory是一个用Rust编写的工具，解决了AI编程助手长期记忆的问题。它能在Claude Code、Cursor等不同AI工具间共享记忆，让你切换工具时不会丢失上下文。安装很简单：cargo install ai-memory，然后运行ai-memory run就能连接到支持的AI助手。

它支持多用户认证，知识按项目共享，个人交接保持私密。这个工具特别适合团队协作，或者需要在多个设备间切换工作流的开发者。项目5个月前创建，目前已有9678星，虽然单日增长只有208星，但稳定性和实用性得到了认可。

🔗 https://github.com/akitaonrails/ai-memory

3️⃣ android/skills
⭐ 8.2k 星 · Kotlin

Android skills是谷歌官方推出的AI优化技能库，用Kotlin编写，专门帮助AI更好地理解和执行Android开发最佳实践。安装很简单：android skills add r8-analyzer --project=.，或者android skills add --all安装所有技能。

这些技能以markdown文件形式存在，专注于LLM表现不佳的领域。项目7个月前创建，已有8247星，单日新增368星。经常使用Android开发并希望AI能更好理解项目结构的人会特别喜欢这个工具，它能让AI助手更准确地理解你的代码结构。

🔗 https://github.com/android/skills

4️⃣ NandhaKishorM/laya 🆕
⭐ 33.2k 星 · Python

Laya是一个用Python写的非自回归系统1决策引擎，支持100多种语言，能在33毫秒内完成决策。安装很简单：python -m pip install laya。

它支持多种扩展，如HTTP服务器、MCP服务器、LangChain集成等。这个引擎适合需要快速分类和决策的场景，比如处理多语言文本或进行快速判断。经常需要处理多语言文本的人会喜欢这个工具，特别是那些需要快速决策的场景。

🔗 https://github.com/NandhaKishorM/laya

5️⃣ Niko1221/Strata 🆕
⭐ 26.6k 星 · C++

Strata是一个C++编写的推理引擎，能让普通PC运行1250亿参数的Qwen3.8-Flash-Next模型。它支持NVIDIA和AMD显卡，需要12GB以上显存。

安装很简单：从GitHub下载最新版本，或者使用brew install --cask robbietilton-strata。不同模型大小速度不同，RTX 5070上Q2_0模型能达到94 tokens/s的输出速度。这个工具适合那些想尝试大模型但没条件租用服务器的开发者，普通游戏PC就能运行。

🔗 https://github.com/Niko1221/Strata

7️⃣ robbietilton/Compositor 🆕
⭐ 17.3k 星 · Swift

Compositor是用Swift编写的Mac图像编辑器，作为Photoshop的免费开源替代品。它支持图层和文件夹、多种混合模式、调整图层、图层效果等高级功能。安装很简单：brew install --cask robbietilton-compositor。

它还支持选区工具、画笔、渐变工具、形状工具、文字工具等，几乎涵盖了日常图像编辑所需的所有功能。需要图像编辑功能但不想支付Photoshop高昂费用的Mac用户，特别是那些熟悉Photoshop工作流程的人。

8️⃣ storytold/pdfcraft 🆕
⭐ 15.2k 星 · Rust

PdfCraft是用纯Rust从零开始编写的开源PDF工作台，支持阅读、组织、合并、分割和保护PDF文件。它支持macOS、Windows、Linux、FreeBSD和Web平台。安装很简单：从getartcraft.com下载或使用包管理器安装。

它支持真实世界的排版，包括世界脚本、垂直日语、彩色表情符号、渐变等。每个保存都是原子操作，撤销功能深入，即使意外关闭也不会丢失内容。需要处理PDF文件但不想使用Adobe Acrobat的人和设计师，特别是那些重视隐私和离线工作的人。
