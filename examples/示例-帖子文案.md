# XERJ：AI搜索新方式，40倍于grep的效率

今天榜单上有个新面孔XERJ特别亮眼，4个月就斩获7360星，单日新增1100多星。这个AI搜索工具用Rust编写，能自动索引代码、文档、日志和PDF，比传统grep节省40倍token。还有Android官方推出的AI技能库和能在普通PC上运行125B参数模型的Strata也值得关注。

TOP1 xerj-org/xerj  ★7.4k (今日+1,102星)
还在挨个文件翻代码？XERJ帮你解决。这个本地AI搜索工具用Rust编写，能自动索引任何文件夹，让AI助手不再逐个读取文件，而是直接获取所需代码。安装非常简单，一条命令`curl -fsSL https://xerj.org/get | sh`就能搞定。使用时，`xerj autoindex ~/my-project`可以自动索引项目，`xerj search "how do we rotate the WAL segment"`进行搜索，`xerj def "euler_to_rotationmatrix"`则能跳转到定义。与传统的grep和sed相比，XERJ能节省40倍的token使用量，同时保持与Elasticsearch的兼容性。经常需要在大代码库中查找特定功能的开发者，以及希望AI助手能更快理解项目结构的用户会喜欢这个工具。
https://github.com/xerj-org/xerj

TOP2 akitaonrails/ai-memory  ★9.7k (今日+208星)
ai-memory为AI编程助手提供长期记忆，用Rust编写。它能解决不同AI工具之间的记忆断层问题，让Claude Code、Cursor、Gemini CLI等不同平台的助手共享记忆。安装后，`ai-memory run`命令可以让不同助手接手工作，无需重新解释项目背景。团队协作场景下，当你从Claude Code切换到Codex时，后者能立即了解你之前的工作进度和遇到的问题。ai-memory支持跨设备同步，无论你在桌面还是笔记本工作，都能保持相同的上下文。
https://github.com/akitaonrails/ai-memory

TOP3 android/skills  ★8.2k (今日+368星)
Android官方推出的AI技能库专门为Android开发优化的模块化指令集合。这些技能以SKILL.md文件的形式存在，帮助AI助手更好地理解和执行Android开发中的特定模式。安装方式很简单，`android skills add r8-analyzer --project=.`就能添加特定技能，`android skills add --all`则安装所有技能。这个项目关注LLM表现不佳的领域，而不是那些AI已经擅长的基本Jetpack Compose最佳实践。需要频繁进行Android开发的程序员，这些技能能显著提高AI助手的代码质量。

TOP4 NandhaKishorM/laya  ★33.2k 
Laya是一个多语言的非自回归系统决策引擎，用Python编写。它能在100多种语言中进行类型化选择、评分和是/否决策，单次前向传播仅需33毫秒。安装非常简单，`python -m pip install laya`即可。使用时，`router.predict(text, questions, model="multilingual")`就能进行多语言决策。需要处理多语言文本分类和决策的场景，比如自动判断用户评论的情感倾向，Laya是个好选择。它使用强化学习训练，支持长文档处理，最多可读取8192个token。
https://github.com/NandhaKishorM/laya

https://github.com/Niko1221/Strata
